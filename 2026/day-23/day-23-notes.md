# Day 23 Notes

## 1. What is a branch?
A branch is a separate line of development to work without affecting main code.

## 2. Why use branches?
To work on features safely without breaking main branch.

## 3. What is HEAD?
HEAD points to the current branch/commit you are working on.

## 4. What happens when switching branches?
Files change to match that branch’s state.

## 5. origin vs upstream
origin → your repo  
upstream → original repo (forked from)

## 6. fetch vs pull
fetch → downloads changes  
pull → downloads + merges

## 7. clone vs fork
clone → copy repo locally  
fork → copy repo on GitHub

## 8. When to use?
clone → when you own repo  
fork → when contributing to others repo
